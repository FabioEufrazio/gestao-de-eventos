# Gestão de Eventos — Coquetelaria & Bar

Sistema completo de gestão de eventos, coquetelaria, controle de insumos e fichas técnicas, orçamentos comerciais, funil de vendas (CRM) e checklist operacional para eventos.

## 🚀 Funcionalidades

- **1. Propostas Comerciais:** Criação rápida de propostas personalizadas com cálculo dinâmico de margem e custos.
- **2. CRM & Clientes:** Gestão de clientes e histórico de interações.
- **3. Fichas Técnicas & Drinques:** Cadastro de receitas, volumetria, modo de preparo e precificação por drinque.
- **4. Produtos & Insumos:** Catálogo e controle de custos de garrafas, frutas, descartáveis e insumos.
- **5. Utensílios & Estrutura:** Checklist de itens de bar, taças, copos e equipamentos.
- **6. Checklist Operacional:** Lista de checagem pré e pós evento.
- **7. Funil de Vendas:** Acompanhamento visual dos status das negociações.
- **8. Exportação & Relatórios:** Emissão de propostas em PDF e planilhas em Excel (.xlsx).

## 💻 Tecnologias

- HTML5 / CSS3 / JavaScript (Vanilla modular)
- TailwindCSS (via CDN)
- Lucide Icons
- jsPDF (Geração de PDFs comerciais e listas)
- SheetJS / xlsx (Importação e exportação de planilhas)
- PWA (Progressive Web App com Service Worker)

## 📦 Como Executar

Por ser uma aplicação baseada em padrões web modernos, basta abrir o arquivo `index.html` em qualquer navegador web ou servi-lo utilizando uma extensão como o *Live Server* do VS Code.
